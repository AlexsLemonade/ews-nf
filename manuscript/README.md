This folder contains scripts and figures related to analysis for the Sean Karl cohort manuscript. 

The `scripts` folder contains scripts used to generate any figures or intermediate files. 

The `full-cohort-metaprograms` folder contains the results from generating metaprograms across the full cohort. 
The files in this folder were generated by the `save-mp-results.R` in the `scripts` directory. 

* `k-7_metaprogram-top-genes.tsv`: This file contains the top 200 genes associated with each metaprogram. 
* `k-7_ora-results.tsv`: This file contains the full set of results from running overrepresentation analysis on the top 200 genes for each metaprogram. 
The Hallmarks and Reactome collections from `MSigDb` were used alongside a custom list of Ewing-specific gene sets found in `../genesets/custom-gene-sets.tsv`.
