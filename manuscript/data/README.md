This folder contains input data used to generate figures. 

Data for individual samples should be copied from the shared `OneDrive` for the Sean Karl Cohort to this folder prior to running any scripts in the `scripts` directory to generate figures. 
The data itself should not be committed to GitHub. 

Output from the metaprogram workflow (in the `metaprograms`) should be copied from the Pittsburgh HTC. 
The output from `ews-nf` can be found at `/vast/acillo/alhawk01/ews-nf-out`.
