Comparison of Goodspeed metaprograms to the Sean Karl Cohort metaprograms

Ally Hawkins

2026-06-16

This notebook compares metaprograms generated from the Goodspeed public dataset to those from the full Sean Karl Cohort. For reference, the Goodspeed data has k=11 metaprograms and the full SKC has k=7 metaprograms. Note that 7 of these metaprograms are patient-specific, so we will only consider 4 metaprograms from the Goodspeed project.

This notebook requires files created from running analyses/scripts/generate-mp-metrics.sh.

Overlap in gene sets from ORA

When looking at the reports, I did notice that some of the gene sets we observed in the SKC were also popping up in the goodspeed cohort. For the goodspeed cohort, MP01 had EWS-high gene sets, MP02 had some inflammatory signatures, and MP03 had some cycling signatures.

Let’s look at the intersection of the gene sets identified through ORA for each set of metaprograms. We’ll report both the Jaccard and the percentage of each gene sets from one cohort shared with the gene sets in the other cohort.

# pull out the ora results 
skc_ora_df <- skc_metrics$ora_results_df
goodspeed_ora_df <- goodspeed_metrics$ora_results_df

In this table, the pct_overlap_skc tells us what percentage of gene sets in the SKC metaprogram are also found in the goodspeed metaprograms and vice versa for pct_overlap_goodspeed.

It looks like we see a lot of overlap between MP06 in SKC (cycling) and MP03 in goodspeed. We also see that 100% of gene sets from MP01 in SKC (EWS-high) are found in MP01 of goodspeed. There may be some small evidence of overlap between MP04 in SKC (inflammatory) with MP02 of goodspeed, but the percentages of shared gene sets start to drop off around this point in the table. This is interesting because even though we don’t see overlap at the individual gene level, we are getting some of the same gene sets back suggesting they are from the same pathways.

Use existing metaprograms to score SCEs

Another thing we can do is use the SKC metaprograms to score all tumor cells in the goodspeed cohort and see if there’s a) detectable scores for any metaprograms and b) any variation in the scores across cells. First, we’ll just look at the distribution of scores for each metaprogram.

ggplot(scores_df, aes(x = log1p(mp_score), y = metaprogram)) +
  ggridges::geom_density_ridges2()

This plot doesn’t really tell me a whole lot. We may have some evidence for MP01 with everything but MP02 showing at least some minor spread in their distribution.

What if we look at the scores for individual cells in a UMAP to see if we can find areas that have high scores for specific metaprograms? To do that, we’ll actually use the merged object with all samples downloaded from the Portal. To make a nicer UMAP, we’ll also integrate the samples using Harmony with participant_id as a covariate, because why not.

# read in the merged sce and integrate? 
harmony_pca <- harmony::RunHarmony(
  data_mat = reducedDim(merged_sce, "PCA"),
  meta_data = colData(merged_sce),
  vars_use = c("participant_id")
)
# Store PCA as `harmony_PCA`
reducedDim(merged_sce, "harmony_PCA") <- harmony_pca

# calculate UMAP on this PCA matrix with appropriate names
merged_sce <- scater::runUMAP(merged_sce,
                              dimred = "harmony_PCA",
                              name   = "harmony_UMAP")
# prep the scores dataframe for joining by adding a cell_id column
scores_df <- scores_df |> 
  dplyr::mutate(
    cell_id = glue::glue("{unique_id}-{barcodes}")
  )

# combine UMAPs, scores, and annotations all together for plotting
all_info_df <- scater::makePerCellDF(
  merged_sce,
  use.dimred = "harmony_UMAP"
) |> 
  dplyr::left_join(scores_df, by = c("cell_id", "barcodes")) |> 
  dplyr::left_join(annotations_df, by = c("cell_id"))

# extract just the tumor cells to plot 
tumor_plot_df <- all_info_df |> 
  dplyr::filter(
    stringr::str_detect(annotation_tier0, "tumor")
  )
ggplot(tumor_plot_df, aes(x = harmony_UMAP.1, y = harmony_UMAP.2, color = mp_score)) +
  geom_point(alpha = 0.2, size = 0.1) +
  facet_wrap(vars(metaprogram)) +
  scale_color_viridis_c()

Hmmm… I do see a group of cells on the left that might have some presence of MP06 (cycling), but I don’t see a ton of other spots with scores. This is not overly impressive to me and I think could be related to the genes from these metaprograms just not being very highly expressed in this cohort? We did have a lot of trouble calling tumor cells originally because of the low expression of EWS::FLI1 targets, so I worry about making too many conclusions here.

Out of curiosity, let’s also look at how consistent the annotations from ews-nf are with the annotations from Opengoodspeed for this cohort. Here, we’ll just make a table of tumor/normal and compare.

One thing I noticed when looking at the reports from ews-nf is that using the CNV cutoff of z > 2 left almost no tumor cells, whereas in the SKC we get plenty of tumor cells. Again, the low expression in this dataset and low CNV calls could indicate overall lower quality here.

Using AUCell to score metaprograms

As a final ditch effort, let’s use AUCell with the 200 genes from each metaprogram to assign AUC values to each cell in our merged object. We can then plot the distribution of the AUC values to see if there is any evidence for activity of any of these gene sets.

# build rankings from SCE (only needs to be done once)
cell_rankings <- AUCell::AUCell_buildRankings(counts(merged_sce))

# calculate AUC for all metaprograms at once
auc_scores <-AUCell::AUCell_calcAUC(
  skc_metrics$top_genes, 
  aucMaxRank = ceiling(0.01 * nrow(cell_rankings)), 
  cell_rankings
)

# extract AUC matrix and plot distribution for each metaprogram
auc_df <- as.data.frame(t(assay(auc_scores))) |>
  tibble::rownames_to_column("cell_id") |>
  tidyr::pivot_longer(-cell_id, names_to = "metaprogram", values_to = "auc")

ggplot(auc_df, aes(x = auc)) +
  geom_histogram(bins = 50) +
  facet_wrap(vars(metaprogram)) +
  labs(x = "AUC", y = "Cell count") +
  theme_bw()

So we do see some presence of genes from MP01, which is the EWS-high gene set, so that makes me feel a little better. We also see that almost all cells have this gene set and maybe a small bump at the beginning of cells that don’t.

We also see maybe a little bit of a tail for MP06 (cycling), which suggests presence of those genes in a subset of cells. Other than that, I don’t really see anything that would indicate presence of the metaprograms from the SKC in this cohort.

Conclusions

In general, I don’t think we can say anything about these metaprograms being reproduced in the goodspeed cohort. I think a lot of that might be due to quality of the sequencing data. It is at least comforting to see that MP01 (EWS-high) and MP06 (cycling) show some level of activity, since at a minimum I would expect these to be present.
