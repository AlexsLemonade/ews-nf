* `sample-metadata.tsv`: This file is the sample metadata file copied from [`ScPCA-admin/sample_info/bailey_cillo/sample-metadata.tsv`](https://github.com/AlexsLemonade/ScPCA-admin/blob/main/sample_info/bailey_cillo/sample-metadata.tsv). 
* `low-cell-count-metadata.tsv`: This file contains a list of sample IDs that should be excluded when generating subsets of samples. 
These samples have fewer than 200 cells in the processed objects. 
* `sample-subsets.tsv`: This file contains all subsets used for testing saturation of metaprograms. 
This file is generated by the `generate-sample-subsets.R` script in the `scripts` directory. 

The `scripts` directory contains any scripts used to set up metadata files. 

* `generate-sample-subsets.R`: This script creates the `sample-subsets.tsv` file by randomly sampling sample IDs to create subsets of various sizes. 
In particular, we create subsets of size 10 to 100 with a step size of 10. 
For each size, sampling is repeated five times. 
For each subset, we ensure that a given patient comprises no more than 10% of samples.
